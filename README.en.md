# OpenWE

OpenWE is an open-source project based on the fangame **Super Mario Maker World Engine** (the Andoyt versions). This project provides the community with the tools needed to create and customize their own versions of World Engine.

> 📄 Español: [README.md](README.md)

## How to use OpenWE?

```js
// Uses: GameMaker Studio 2
// Extensions to download: FolderPick, NekoPresence.
```

Basic programming knowledge (GML) is required.

## Mods

This project includes a Lua modloader: you can create mods as zip files containing a `main.lua` and drop them into the `mods/` folder. A full guide covering the entire API, all events and examples is in [MODDING.md](MODDING.md).
